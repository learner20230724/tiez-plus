# 手机 0.1.3：待发送内容留在首页

推送按钮面向所有当前发现的 Plus 电脑，不需要到设置逐台选择。设置中的选择只控制拉取来源。手机仍需与电脑处于同一可信局域网，电脑需运行 Plus。

发送前在本机持久保存待发内容，未完成的内容留在首页；只有某条内容本次全部目标都确认送达，才清空该条未被继续编辑的输入。部分失败时，历史中只展示成功的送达记录，原内容继续留在首页。

再次点击推送是一次新的发送，发给当前全部目标，包括之前成功收到的电脑；不再限制原电脑。这个行为可以在换电脑后直接继续使用。断网重连不会自动发送。

首页剪贴板卡片、待推送卡片、输入框均可长按删除。删除会保存空白标记防止延迟保存恢复旧内容。升级时将旧版历史中未确认的内容恢复到首页；内部回执仍用于确认送达，但失败记录不展示在历史列表。
