# 验收与隔离边界

## 已执行的自动化（构建期）

可复现命令及最终结果在 `TEST-RESULTS.md`。测试实现位于 `tests/` 和桌面 `services/plus/core.rs`、`services/file_transfer/security.rs`。

- UTF-8 字节边界；万字中文、多行、空白、表情、原文一致。
- SQLite 事务写入失败回滚；未选草稿、发送期间继续编辑、部分成功、迟到回执与版本碰撞。
- 临时文件数据库进程强制终止后重新打开 WAL，草稿和发件正文仍在，sending 恢复为未确认；**这是存储协议测试，不冒充 Android 杀进程实测**。
- Broker 在线/电脑不在线只收到 PUBACK，不能报告送达；电脑收到但回执丢失保持未确认；关闭重连不自动重放。
- MQTT 真 Broker + 手机传输客户端联调，电脑为模拟协议端，不调用 Windows 剪贴板。
- 拉取/刷新没有剪贴板写入副作用；显式复制获取全文，获取失败不更改模拟剪贴板，写入 false 不报成功。
- 90 天清理仅已确认记录；失败、未知和草稿保留。
- 端口占用时另选 TCP 端口且原监听仍存活；通配符订阅、冒充来源、跨来源注册受限。
- 桌面去重/崩溃状态机、事务回滚、消息 ID 正文不一致拒绝；文件传输会话授权、Origin、路径校验。
- 自动选唯一实例、多个实例不默认选、记忆身份随 IP 更新、不悄悄切换另一电脑。
- 原目录 304 个源文件的 SHA-256 与初始快照一致；旧 `TieZLocalMqttServer` 保持运行。
