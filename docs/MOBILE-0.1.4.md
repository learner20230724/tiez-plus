# 手机测试版 0.1.4

解决合盖休眠电脑仍被局域网发现时，手机反复弹出部分失败提示的问题。

- 推送目标仍为当前所有已发现的 Plus 电脑。
- 每条内容任意一台确认送达，即按成功处理并立即清空其首页输入；发送期间新编辑的文字不会被清掉。
- 其它电脑失败不弹窗、不展示送达比例，也不会让这条内容继续留在首页。成功推送不再弹出提示条，保留轻触反馈。
- 如果某条内容没有任何电脑确认收到，继续保留它，并提示尚未送达。
- 拉取目标选择和长按删除行为不变。

版本：0.1.4 / versionCode 5。包名 `io.github.learner20230724.tiezplus.test`，沿用 0.1.3 测试签名，可覆盖测试版；仍与正式旧版独立。

验证：TypeScript 与版本检查通过；完整自动测试 59 项通过，8 项 Windows 专属测试跳过。真实双 MQTT 服务测试验证一台成功、另一台延迟失败时提前清空内容且不报部分失败；全部失败时仍保留内容。尚未进行物理手机与合盖 Mac 的现场验收。
