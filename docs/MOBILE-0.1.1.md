# TIEZ Plus 手机 0.1.1

日期：2026-09-20。本次只调整 Plus 手机端和 Android 打包脚本，没有改动正在使用的 Windows 服务、客户端、系统剪贴板或旧项目。

## 使用方式

- 首页继续使用原主题设置（深色 / 浅色 / 系统）和底部三个导航：同步、文件传输、设置。
- 第一条自动读取手机剪贴板；短内容一行，长内容最多三行，长按可看全文。只是预览收起，保存和发送仍然使用完整原文。
- 自动保存输入并提供下一条空输入，不显示“新增草稿”。右下角按钮只写“推送”。
- 推送先把本次选中的完整文本事务性保存到手机历史，再清空这些输入；没有保存成功、未选中或正在继续编辑的文本不清空。电脑的送达状态仍严格以应用层回执为准。
- 右上角小“历史”按钮：点击一条历史，把全文加入待推送列表；不会立即发送，不会改变剪贴板。失败记录原样重试复用原消息 ID；成功记录主动再推送使用新 ID。长按或点省略号可查看全文、复制、编辑、删除（需确认）。
- 拉取的电脑当前内容和历史：点击才复制。历史摘要不是复制正文，复制前获取完整正文；读取或写入失败不报告成功。拉取、刷新本身不写入剪贴板。
- 电脑自动发现、多实例选择、状态诊断、扫码都在“设置 → 电脑连接”。连接生命周期仍属于应用，不依赖设置页是否打开。

## 原地升级

安装 `artifacts/TIEZ-Plus-0.1.1-arm64-v8a.apk`，**直接覆盖 Plus 0.1.0，不要先卸载或清除数据**。

- 包名保持 `io.github.learner20230724.tiezplus`，versionName `0.1.1` / versionCode `2`。
- 使用相同 Plus release 签名。公钥证书 SHA-256：`b91168536b754de321972b053749155ba5a20299b1bab8042862c01ff1cac2d5`。
- SQLite 使用增量加列迁移，不删除或重建现有草稿、发件表。原失败/未知记录继续保留，已送达记录仍按原 90 天规则清理。
- 原版 TieZ 是另一个应用；此包不会覆盖原版，也不读取原版数据库。
- 未发现过任何电脑时，推送仍保留输入为草稿并提示去连接，不丢弃内容。保存失败也不会清空输入。
